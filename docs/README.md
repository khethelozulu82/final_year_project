# Docs

- `/meetings/` — one file per meeting, named `YYYY-MM-DD.md`, logging attendance, decisions, and action items
- `/proposals/` — project proposal and supervisor approval documents
- `/reports/` — progress reports, final report drafts
- `/presentations/` - presentations
## Meeting minutes template

```
## Meeting: YYYY-MM-DD

**Attendees:**

**Agenda:**

**Decisions:**

**Action items:**
- [ ] Task —> Owner —> Due date
```
